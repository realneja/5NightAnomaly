## Cara membuka

Buka folder ini lewat Unity Hub dengan Unity 6000.6.5f1. Scene pertama ada di `Assets/_Game/Scenes/MainMenu.unity`. Tekan Play, lalu pilih PLAY untuk masuk ke scene `NightLaneDemo`.

Isi saat ini: main menu (SETTING untuk volume, CREDIT untuk daftar tim) dan scene demo tempat Pengembara berjalan dan menyerang dummy latihan serta slime.

## Kontrol

A/D atau panah kiri dan kanan untuk berjalan, W/S untuk naik turun jalur. Klik kiri atau Enter untuk menyerang, tahan untuk charge attack. Tombol 1 sampai 4 mengganti senjata: lentera, petir Zeus, tongkat api, tangan kosong.
